🤖 آموزش اتصال در اندروید (v2rayNG / MahsaNG)

۱. نرم‌افزار مورد نظر را دانلود و نصب کنید:
📲 دانلود v2rayNG (گوگل پلی) 📲 دانلود MahsaNG (گوگل پلی)
۲. لینک اختصاصی دریافت شده از ربات را کپی کنید.
۳. وارد برنامه شده، علامت + بالای صفحه را بزنید و گزینه Import config from Clipboard را انتخاب کنید.
۴. روی دکمه دایره‌ای اتصال کلیک کنید تا متصل شوید.

🍎 آموزش اتصال در آیفون (Streisand / V2Box)

۱. نرم‌افزار مورد نظر را از اپ استور دانلود کنید:
🍏 دانلود Streisand (اپ استور) 🍏 دانلود V2Box (اپ استور)
۲. لینک اشتراک خود را کپی کنید.
۳. وارد برنامه شده، دکمه + یا Add Subscription را بزنید.
۴. لینک کپی شده را قرار داده و ذخیره (Save) کنید، سپس اتصال را فعال نمایید.

💻 آموزش اتصال در ویندوز (v2rayN)

۱. نرم‌افزار v2rayN را دانلود و از حالت فشرده خارج کنید:
💻 دانلود v2rayN (گیت‌هاب)
۲. کانفیگ یا لینک دریافت شده را کپی کنید.
۳. درون برنامه کلیدهای ترکیبی Ctrl + V را بزنید تا سرورها اضافه شوند.
۴. روی آیکون برنامه در تسک‌بار راست کلیک کرده و System Proxy را روی حالت Set System Proxy بگذارید.

🍏 آموزش اتصال در مک‌بوک (V2Box / Sing-Box)

۱. نرم‌افزار مورد نظر را برای مک دانلود کنید:
🍏 دانلود V2Box (اپ استور) 🍏 دانلود Sing-Box (گیت‌هاب)
۲. لینک خریداری شده را کپی نمایید.
۳. در بخش Configs گزینه Import Subscription را انتخاب کنید و لینک را وارد کنید.
۴. دکمه Connect را بزنید تا سرویس شما متصل شود.
